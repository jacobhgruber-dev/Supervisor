The 30-second explanation

What am I actually setting up?

If you've never used an AI coding agent, here's the whole idea in plain English — no jargon.

OpenCode is a free app that runs in your terminal. On its own it's just a chat box for an AI. This repo upgrades it into a Supervisor — think of hiring a project manager instead of a single freelancer. You give one instruction; the Supervisor splits it into tasks, hands each to the right specialist, checks the work, fixes mistakes, and reports back.
An API key is a long password that lets your computer talk to an AI model over the internet. The model runs on the provider's servers, not your laptop, and you pay a tiny amount per use. The default model here — DeepSeek — is so cheap that a few dollars of credit lasts weeks. Treat the key like a password: never share it, and you can revoke it anytime.
Quick start

Zero to hero, in 6 steps

Paste each grey box into your terminal (Mac: press Cmd+Space, type “Terminal”). The full hand-holding version — with screenshots-in-words and every footgun explained — is in the complete guide.

1

Install OpenCode

Needs Node.js first (check with node --version).

npm install -g opencode
2

Get a DeepSeek API key

The only key you need to start. Sign up at platform.deepseek.com, add $2–$5 of credit, then create a key (starts with sk-). Copy it now — you can't view it again.

3

Copy the files into place

Download the repo, then run the one-liner installer. It copies everything into OpenCode's config folder — and safely merges the config instead of overwriting it (your existing settings always win).

git clone https://github.com/jacobhgruber-dev/Supervisor.git cd Supervisor ./install.sh # macOS / Linux — or run: .\setup.ps1 (Windows PowerShell)

New machine? Run the Dependency Doctor first — it scans your system and prints a tailored install command for every missing tool:

./install.sh --doctor # never fails, writes nothing — just tells you what's missing

Prefer to do it by hand? The manual copy below is the reference — same result, one file at a time.

mkdir -p ~/.config/opencode/agent ~/.config/opencode/agents # If you already configured providers in Desktop (Settings → Providers), skip the opencode.template.json copy — you only need the agents, plugin, and AGENTS.md. cp opencode.template.json ~/.config/opencode/opencode.json cp agent/supervisor.md ~/.config/opencode/agent/supervisor.md # Supervisor → agent/ cp agents/*.md ~/.config/opencode/agents/ # subagents → agents/ cp plugin/observer-bridge.js ~/.config/opencode/ cp AGENTS.md ~/.config/opencode/AGENTS.md
📌 Where agents go: OpenCode loads both agent/ and agents/. This install puts the Supervisor in agent/ and subagents in agents/. What makes the Supervisor primary is mode: primary in its frontmatter. Don't drop non-agent docs into either folder (phantom agents).
4

Connect your key (no file editing)

Let OpenCode store your key securely — it never goes in the repo config.

opencode auth login

Choose DeepSeek (or Other → deepseek) and paste your sk-... key. Later, run it again and choose Anthropic to unlock the Claude tiers, or Google to activate Observer — the built-in screenshot vision (see below).

5

Launch & pick the Supervisor

opencode

Open the agent selector and choose Supervisor. You're now talking to your project manager.

6

Give it your first task 🏆

Try one of these and watch it delegate, review, and report back on its own:

"Review this project and tell me what needs work" "Build a small command-line to-do app in Python" "Fix the login bug"

Built-in vision

Observer — paste a screenshot, get an analysis

Your Supervisor runs on a text-only model, so it can't see images. Observer is its eyes: paste a screenshot of an error, a UI bug, or a design mockup into chat and Observer reads it — extracting text, locating the problem, and handing the Supervisor a description it can act on.

Dual multimodal vision, zero setup. Observer's primary model is Google Gemini 3.8 Flash. If only Anthropic is configured (no Google key), the Observer plugin automatically falls back to Claude Sonnet 5 — the same structured analysis, either way. Connect a key with opencode auth login and the paste-a-screenshot bridge just works.
Common questions

Beginner FAQ

Is this going to cost a lot?

No. The software is free. DeepSeek (the default) charges a fraction of a cent per task — most people load $2–$5 and it lasts weeks. Claude's “senior” tier is far pricier, so it's used only when you explicitly ask.

The Supervisor doesn't show up. What did I do wrong?

Confirm supervisor.md is at ~/.config/opencode/agent/supervisor.md and that its frontmatter says mode: primary. Re-run the Step 3 copy commands if the file is missing.

I get “insufficient balance” errors.

Your key works, but the account has $0. Add a few dollars of credit at platform.deepseek.com and try again.

What are the “mcp” entries in the config? Do I need them?

Two tools ship enabled and need no keys: playwright (drives a real browser — clicks, forms, login flows) and a11y-color-contrast (WCAG color-contrast checks for design work). Thirteen more are optional nice-to-haves, disabled by default — chrome-devtools, elevenlabs, railway, screenpipe (screen history), macos-automator (native Mac control), yt-dlp, vercel, gemini-api-docs, context7 (live library docs), github (issues/PRs), macos-use (Mac GUI control), firecrawl, and twenty-first — turn one on only if you want it. (On Windows, the installer drops the macOS-only ones — swap in Windows-MCP for native desktop control.) The Supervisor runs perfectly without any of them. See the guide for how to enable one.

I already have an OpenCode config — will this overwrite it?

Don't copy opencode.template.json over your existing one. The config only has MCP servers and permissions — merge what you need. The .md agent files are safe to add as-is.
